# 文件存储

服务提供需要登录的本地文件存储。文件内容保存在 `FILE_STORAGE_ROOT`，MySQL 的 `stored_files` 表保存所有者、原文件名、类型、大小、SHA-256 和创建时间。磁盘文件使用随机 UUID 命名，响应不会暴露服务器路径。

默认单文件上限为 50 MB，每位用户总量上限为 1 GB。生产环境应把目录配置到持久磁盘并纳入备份：

```dotenv
FILE_STORAGE_ROOT=/srv/nest-learning/files
FILE_MAX_SIZE_BYTES=52428800
FILE_USER_QUOTA_BYTES=1073741824
```

修改配置后重启服务。首次启用需执行迁移：

```bash
./node_modules/.bin/typeorm-ts-node-esm migration:run -d data-source.ts
```

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/files` | 以 `multipart/form-data` 上传，字段名为 `file` |
| `GET` | `/files` | 普通用户查看本人文件；超级管理员查看全部 |
| `GET` | `/files/:id/download` | 本人或超级管理员下载 |
| `DELETE` | `/files/:id` | 本人或超级管理员删除文件和元数据 |

上传：

```bash
curl -X POST http://127.0.0.1:3000/files \
  -H 'Authorization: Bearer <accessToken>' \
  -F 'file=@/absolute/path/report.pdf'
```

响应中的 `Results` 示例：

```json
{
  "id": "文件 UUID",
  "ownerUserId": "用户 UUID",
  "originalName": "report.pdf",
  "mimeType": "application/pdf",
  "size": 12345,
  "sha256": "...",
  "createdAt": "2026-09-19T00:00:00.000Z",
  "downloadUrl": "/files/文件 UUID/download"
}
```

列出和下载：

```bash
curl -H 'Authorization: Bearer <accessToken>' http://127.0.0.1:3000/files
curl -L -H 'Authorization: Bearer <accessToken>' \
  http://127.0.0.1:3000/files/<文件UUID>/download \
  --output downloaded-file
```

删除：

```bash
curl -X DELETE -H 'Authorization: Bearer <accessToken>' \
  http://127.0.0.1:3000/files/<文件UUID>
```

当前实现适合单机部署。多实例部署需要让所有实例挂载同一持久卷，或把文件内容提供者替换成 S3、MinIO 等对象存储。
