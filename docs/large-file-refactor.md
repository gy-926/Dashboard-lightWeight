## 验证边界

前端使用 Vitest、vue-tsc 和生产构建；后端使用 Vitest、构建和 Lint。真实 MySQL 集成测试需要独立测试数据库，本轮不使用业务数据库执行测试。

## 阶段复审记录

### 1. 具体缺陷

复审了前后端删除约束、保存失败时的草稿保留、JSON 文本与对象分离、UMD 部分成功后的状态更新。前端 81 项、后端 42 项测试通过，vue-tsc、后端构建和 Lint 通过。新增非空菜单删除与 JSON 参数回归测试。

### 2. 菜单配置

入口 2,996 → 117 行。共享状态保持页面级实例，树/节点/关联/弹窗逻辑分别维护；样式以 `.menu-config` 限定范围，避免对子组件重复注入 scoped 样式。复审修复跨模块 ID 生成依赖和类型导入，添加行内保存并发保护。83 项测试、类型检查、生产构建通过；两个浏览器用例验证菜单渲染、非空根目录删除保护与 Home 交互。

### 3. 权限与后端领域

权限入口约 50 行；编辑器分为功能、授权、角色、用户、组织和数据读取。后端 DashboardService 保留构造及公开方法契约，委派给五个领域对象；领域对象共享原 DataSource，事务仍在领域方法内完成。复审补回 typed const 的展示映射导出，核对普通用户/部门交集和会话撤销。前端 84 项、后端 42 项测试通过；三个浏览器用例通过，包括错误 JSON 草稿保留及正确提交。

### 4. 认证界面

登录 1,155 → 271 行，修改密码 1,014 → 226 行，共用 AuthShell 和两份分工明确的样式。主题接收更新不再持久化，正常页面也可同步完整主题。复审核对成功后清空认证、禁止重复提交、卸载时清理计时器；邮件重置改为管理员帮助。五个浏览器用例通过，另核对主题过渡完成后的真实背景色与暗色截图，避免把过渡帧误认为最终外观。生产构建通过。

### 5. Home 与 UMD 管理

Home 1,667 → 44 行；区块各自维护交互和样式，静态内容与实时统计分离。系统名改用响应式配置；加载进度不再伪造最低 8%。UMD 管理 808 → 76 行，分析和版本控制分别维护；关闭/卸载后用代次忽略迟到结果，版本列表采用最新请求结果。复审核对导航事件、暗色祖先选择器、Teleport 和文件输入引用，补充两个浏览器用例并修正对加载器查询参数的测试匹配，两项均通过。前端 86 项测试、类型和生产构建通过。

### 6. 路由与整体回归

路由入口 673 → 114 行，配置、缓存、菜单转换和组件转换分别维护，原导出路径保持兼容。补充缓存身份恢复、用户/项目隔离、过期与版本校验测试。整体复审发现并修复三处问题：关联行保存覆盖根目录未保存草稿；短窗口下功能表格被压缩而无法操作；关闭 PageHost 标签到路由跳转之间旧链路重新挂载远程 Vue，产生残留样式。路径销毁后继续预留至下一次导航，另补充单元测试。

最终验证：前端 90 项单元测试、后端 42 项单元测试、17 项 Chromium 浏览器测试全部通过；前端类型检查、生产构建、后端构建与 Lint、git diff --check 通过。浏览器测试模拟接口，覆盖菜单、JSON 编辑、主题同步、改密、UMD 延迟结果与部分成功状态，以及 PageHost 保活、关闭、刷新、退出和重新登录。本轮未执行真实 MySQL 集成测试。构建仍提示已有的第三方大包与 Browserslist 数据过旧。
